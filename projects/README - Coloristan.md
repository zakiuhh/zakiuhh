# ColorIstan

A beautiful, minimal web application to identify colors by name and convert between multiple color formats. Built with vanilla JavaScript—no frameworks, no dependencies.

![ColorIstan Screenshot](/assets/ss.png)

## Features

- **Multi-Format Support**: Convert between HEX, RGB, HSL, and OKLCH color formats
- **Smart Autocomplete**: Get color suggestions as you type (by name or code)
- **Color Explorer**: Browse and search through 100+ handpicked colors
- **Name Identification**: Find the closest named color for any color code
- **Clean Interface**: Minimal, distraction-free design
- **Zero Dependencies**: Built with vanilla HTML, CSS, and JavaScript

## Demo

[Live Demo](https://coloristan.vercel.app)

## How to Use

### ColorIstan

1. Enter any color code: `#FF5733`, `rgb(255,87,51)`, `hsl(9,100%,60%)`, or color name like `"red"`
2. Press Enter or select from autocomplete suggestions
3. View the color name and all format conversions

### Explore Colors

- Browse the complete color database
- Search by name or hex code
- Click any color to see detailed information

## Installation

No installation needed! Just open [This](https://coloristan.vercel.app) in your browser.

- **Content Creators**: Find perfect color names for posts
- **Students**: Learn about color formats and conversion

## Color Formats Supported

- **HEX**: `#FF5733`
- **RGB**: `rgb(255, 87, 51)`
- **HSL**: `hsl(9°, 100%, 60%)`
- **OKLCH**: `oklch(0.65 0.2 25)` (Perceptually uniform color space)

## Color Database

Uses a curated database of 100+ named colors. You can easily add more colors by editing the `colorDatabase` array in the JavaScript code.

## Why I Built This

I needed to identify color names for Instagram carousel posts, but couldn't find a simple, clean tool that did exactly what I wanted. So I built one!
