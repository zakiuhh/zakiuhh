# 🎨 SnipCode - Beautiful Code Screenshots

Create stunning, shareable code screenshots with advanced customization options. The most feature-rich code screenshot tool with professional quality exports.

![Version](https://img.shields.io/badge/version-2.0.0-blue)
![Status](https://img.shields.io/badge/status-production%20ready-green)
![Features](https://img.shields.io/badge/features-50+-purple)

## ✨ Highlights

- 🎨 **16 Beautiful Themes** with gradient backgrounds
- 🖼️ **3 Window Frame Styles** (macOS, Windows, None)
- 📐 **5 Aspect Ratio Presets** for social media
- 💡 **Line Highlighting** for emphasis
- 🏷️ **Custom Watermarks** for branding
- 🔗 **URL State Sharing** for collaboration
- 💾 **Preset System** for quick configs
- 📋 **Multiple Export Formats** (PNG, SVG, Markdown)
- 🛡️ **Robust Error Handling** throughout
- 📱 **Fully Responsive** mobile design

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Type or paste your code
3. Customize theme, font, and style
4. Export as PNG, SVG, or copy to clipboard

That's it! No installation, no dependencies.

## 📚 Core Features

### Themes
Choose from 16 professionally designed themes:
- **Vibrant**: Candy, Sunset, Ocean, Aurora, Neon
- **Dark**: Midnight, Forest, Charcoal, Crimson
- **Light**: Arctic, Sand, Blossom
- **Elegant**: Rose, Peach, Lavender, Citrus

### Customization
- **Editor Mode**: Dark or Light
- **Background**: Toggle gradient background on/off
- **Line Numbers**: Show or hide
- **Padding**: 16px, 32px, 64px, or 128px
- **Fonts**: JetBrains Mono, Fira Code, Source Code Pro, System Mono
- **Languages**: 33+ with auto-detection

## 🆕 Advanced Features (v2.0)

### Window Frames
- **macOS**: Classic traffic lights (red, yellow, green)
- **Windows**: Minimize, maximize, close buttons
- **None**: Frameless for minimal look

### Shadow Control
- **None**: Flat design, no shadow
- **Low**: Subtle 15px blur
- **Medium**: Standard 30px blur (default)
- **High**: Dramatic 50px blur

### Aspect Ratios
Optimized dimensions for social media:
- **Free**: Unrestricted resizing
- **Square (1:1)**: Perfect for avatars
- **Twitter (16:9)**: Optimized for tweets
- **Instagram (4:5)**: Instagram-friendly
- **LinkedIn (1.91:1)**: Professional posts

### Line Highlighting
- Hold **Alt** (or **Ctrl**) and click line numbers
- Highlight multiple lines
- Purple emphasis with enhanced contrast
- Persists in exports

### Watermarking
- Add custom text (up to 50 characters)
- Toggle on/off easily
- Appears bottom-right in exports
- Professional, subtle styling

### URL Sharing
- Complete configuration saved in URL
- One-click "Copy Shareable URL"
- Share exact setup with team
- All settings preserved

### Markdown Export
- Export as markdown code blocks
- Auto-detects language syntax
- Copy to clipboard
- Perfect for GitHub, docs, wikis

### Preset Management
- Save favorite configurations
- Name your presets
- Quick switching
- Stored locally in browser

## 📤 Export Options

### PNG Export
- **High Quality**: 2×, 4×, or 6× scale
- **Optimized Rendering**: Fixed choppy exports
- **Smart Anti-aliasing**: Perfect on dark themes
- **Keyboard**: ⌘S or Ctrl+S

### SVG Export
- **Vector Format**: Scales infinitely
- **Small File Size**: Efficient format
- **Clean Code**: Well-formatted output
- **Keyboard**: ⌘⇧S or Ctrl+Shift+S

### Clipboard Copy
- **One-Click**: Copy image instantly
- **Universal**: Paste in Slack, Discord, etc.
- **Keyboard**: ⌘C or Ctrl+C

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘S` / `Ctrl+S` | Save as PNG |
| `⌘⇧S` / `Ctrl+Shift+S` | Save as SVG |
| `⌘C` / `Ctrl+C` | Copy to clipboard |
| `Alt + Click` | Highlight line |
| `Esc` | Close menus |
| `Tab` | Insert spaces |
